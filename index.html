Three kinds of enterprise data.

Six iterations. One piece at a time.

Clean the mess

Raw CSVs land in Bronze tables exactly as they arrive. SQL then cleans them into normalized Silver tables.

2SQL programming

Teach the database to write

A stored procedure turns every service call and claim into a readable record for the AI, with its source attached. Triggers keep a JSON audit trail.

3High availability

Survive a failure

A three-node Galera cluster keeps the data available when a node dies. A ColumnStore table handles the analytics.

Galera clusterfailover testingColumnStore vs InnoDB
4Vector database

Search by meaning

PDFs are split at sentence boundaries, embedded with MiniLM and stored in ChromaDB. The HNSW index was tuned with a benchmark.

chunkingembeddingsHNSWrecall vs speed
0.95recall@5
0.44 msmedian search
5NoSQL + hybrid RAG

Ask across all three

Telemetry goes into MongoDB. A router reads each question, searches the three databases in parallel, and Gemini answers only from what was found. Code checks every citation.

MongoDBquery routingparallel retrievalGeminicitation checks
6Automation + optimization

Run itself, faster

A Python DAG picks up new files and database edits every 10 minutes and re-embeds only what changed. Pooling, caching and index tuning made retrieval 3× faster.

05 · What this project covers

Advanced data management, end to end

Data lakehouse

Bronze and Silver layers, cleansing and 3NF modelling in SQL

SQL programming

Stored procedures, triggers, audit logs and security views

High availability

Galera replication, failover testing, ColumnStore analytics

NoSQL · MongoDB

Nested documents, indexes and aggregation for telemetry

Unstructured data

PDF text and table extraction, sentence-aware chunking

Vector database

Embeddings, ChromaDB, HNSW tuning for recall and speed

LLMs + RAG

Grounded prompts, Gemini, citations and hallucination checks

Pipeline orchestration

A Python DAG with retries, logging and a run lock

Change data capture

Trigger-based CDC and incremental, hash-based updates

Optimization

Profiling, query plans, indexes, connection pooling, caching

Benchmarking

P50 / P95 / P99 per stage, throughput and accuracy

Data provenance

Every answer traced and audited back to its source record
